API Reference

The complete public API of PDEStudioCore.jl.

PDEStudioCore.PDEStudioCore — Module
PDEStudioCore

A headless-safe backend for running, storing and analysing PDE simulations.

Provides strictly typed Eulerian (ESimData) and Lagrangian (LSimData) datasets of any dimension, deterministic parameter hashing with atomic on-disk caching, parameter sweeps through SimulationConfig, and a multithreaded statistics pipeline.

source
PDEStudioCore.AbstractSimData — Type
AbstractSimData{D, DS, M, T <: Real}

Root type of all simulation datasets.

  • D: total (spacetime) dimensions, DS: spatial dimensions (D == DS for static data),
  • M: number of field components, T: floating point precision.
source
PDEStudioCore.DomainInfo — Type
DomainInfo{D, T <: Real}

Metadata describing the bounding box and dimension layout of a dataset.

Fields

  • dim_keys::NTuple{D, Symbol}: ordered axis identifiers, e.g. (:x, :y, :t).
  • mins, maxs::SVector{D, T}: bounding box of the domain.
  • spacing::SVector{D, T}: mean node spacing per axis (used as integration measure).
  • time_dim::Union{Nothing, Symbol}: the time axis (always the last one), or nothing for static data.
  • stat_registry::StatRegistry: the dimensions kept by each statistic of this dataset.

The constructor validates the layout, copies the registry (datasets never share registries) and always registers :Solution => :all.

source
PDEStudioCore.ESimData — Type
ESimData{D, DS, M, T} <: AbstractSimData{D, DS, M, T}

Eulerian data: fields on a structured tensor grid (time, if present, is the last axis).

Fields

  • params::ParamDict: the parameters that produced the data (copied on construction).
  • domain::DomainInfo{D, T}: bounding box, dimension names and statistic registry.
  • axes::NTuple{D, Vector{T}}: coordinate vector of every axis.
  • u::Array{SVector{M, T}, D}: the solution tensor.
  • stats: a StatsView of all statistics. :Solution is always present and is u; derived statistics are stored alongside it.

Prefer create_sim_data for construction; the inner constructor validates that the axes match the solution and that DS matches the domain.

source
PDEStudioCore.LSimData — Type
LSimData{D, DS, M, T} <: AbstractSimData{D, DS, M, T}

Lagrangian data: particle positions and states recorded at discrete times.

Fields

  • params::ParamDict: the parameters that produced the data (copied on construction).
  • domain::DomainInfo{D, T}: bounding box, dimension names and statistic registry.
  • t::Vector{T}: recording times (a single 0 for static data).
  • x::Vector{Vector{SVector{DS, T}}}: particle positions per time step.
  • u::Vector{Vector{SVector{M, T}}}: particle states per time step.
  • stats: a StatsView; :Solution is always present and is u.

PDEStudioCore.SimulationConfig — Type
SimulationConfig

Blueprint of a batch of simulation runs.

Fields

  • shared::ParamDict: baseline parameters of every run (usually contains :sim_func_name).
  • methods::MethodDict: per-method parameter overrides (:ignore => [...] drops shared keys).
  • defaults::Vector{Symbol}: the methods run_all_simulations executes.
  • varied::VariedDict: the parameter sweep (Cartesian product).
  • reference::Union{Symbol, Nothing}: name of a reference factory params -> (x -> u_exact).
  • postprocess::Union{Symbol, Nothing}: name of a function data -> Bool (return true to save).
  • sources::Vector{String}: files included into the target module before running.

PDEStudioCore.StatsView — Type
StatsView{M, T, S} <: AbstractDict{Symbol, AbstractStatTensor{M, T}}

Dictionary view returned by data.stats. It behaves like a Dict, but :Solution is always present and always refers to data.u (reading, writing and iterating it go through the solution field), so the solution can never be missing from or out of sync with the statistics. All other entries are the dataset's derived statistics. copy(data.stats) returns a plain Dict snapshot.

PDEStudioCore.VariedDict — Type
VariedDict

Alias for Dict{Symbol, Vector}: the parameter sweep. The pipeline runs the Cartesian product of all vectors. Keys of the form :Ns__x/:Ns__1 sweep a single entry of the tuple parameter :Ns.

PDEStudioCore.add_stat! — Method
add_stat!(data::AbstractSimData, name::Symbol, value, kept_dims)

Attaches a pre-computed statistic and records the dimensions it keeps (:all, :space, :time, dimension names, or Symbol[] for a scalar) so that conversions and frontends can slice it. Numbers and arrays of numbers are converted to SVectors with the dataset's component count, and shapes are checked against the kept axes (Eulerian) or time steps and particles (Lagrangian).

calculate_all_stats! leaves such statistics alone, unless the same name is registered globally (then it is recomputed with force_overwrite = true or when the kept dimensions differ).

PDEStudioCore.calc_stat — Method
calc_stat(::Val{name}, fixed_coords, u, ana, domain)

Extension point for statistics registered with register_stat!. Called once per retained slice: fixed_coords holds the coordinates of the kept dimensions, u/ana iterate the numerical and reference values of the slice (ana is NaN without a reference function). Must return an SVector{M}. The fallback returns NaNs, which removes the statistic.

source
PDEStudioCore.calculate_all_stats! — Function
calculate_all_stats!(sim_data::AbstractSimData, ref_func = nothing; force_overwrite = false, save = true)

Evaluates every statistic of the global registry (see register_stat!) that is missing from the dataset (or all of them with force_overwrite = true). ref_func(x) is the exact solution at the spacetime point x::SVector{D}; it is evaluated once per node/particle. Statistics that come out all-NaN (e.g. errors without a reference) are dropped. Statistics added with add_stat! are never touched. Saves the dataset when save = true. Returns sim_data.

check_data(data::ESimData; per_step = false)
check_data(data::LSimData)

Summarises the numerical health of a dataset as a DataFrame with the columns Time, then C<c>_Min, C<c>_Max, C<c>_Mean, C<c>_NaNs for every component c. Eulerian data is aggregated into a single row (Time = NaN) unless per_step = true; Lagrangian data gets one row per time step.

PDEStudioCore.convert_to_eulerian — Method
convert_to_eulerian(ldata::LSimData, res::Tuple; spatial_interp = :scatter)

Scatters Lagrangian particles onto a grid with the spacetime resolution res (spatial entries, then the number of time slices). Particle field statistics are scattered as well, time series are resampled to the output times and other statistics are copied. Output times are evenly spaced between the first and last recording time; each takes the nearest recorded particle snapshot (the native times are kept when the number of slices matches).

source
PDEStudioCore.convert_to_lagrangian — Method
convert_to_lagrangian(data::ESimData)

Turns grid nodes into stationary particles (all time steps share one position vector). Full fields become per-particle statistics, purely spatial fields are repeated for every time step and all other statistics are copied.

PDEStudioCore.create_sim_data — Method
create_sim_data(space, u, t, params; dims, time_dim = :t, xmins, xmaxs, tmin, tmax)   # transient Eulerian
create_sim_data(space, u, params; dims, xmins, xmaxs)                                 # static Eulerian
create_sim_data(x, u, t, params; dims, time_dim = :t, xmins, xmaxs, tmin, tmax)       # transient Lagrangian
create_sim_data(x, u, params; dims, xmins, xmaxs)                                     # static Lagrangian

Builds an ESimData or LSimData of any spatial dimension. The global statistic registry is copied into the dataset and :Solution is coupled to u automatically.

Eulerian input

  • space: a coordinate vector (1D), a tuple of axis vectors (x, y, z, ...), or a tuple of ndgrid-style coordinate arrays (x_grid[i, j] == x[i]).
  • u: an array with one dimension per spatial axis (plus a trailing time dimension when t is given) whose elements are SVectors, numbers (a scalar field) or vectors. A numeric array with one extra trailing dimension is read as components-last (u[i, j, n, c]).
  • t: the time vector (time is always the last axis).

Lagrangian input

  • x: particle positions, Vector{Vector{SVector{DS}}} (one vector per time step) or a single Vector{SVector{DS}} for static data.
  • u: particle states with the same layout (SVectors or numbers).

Keywords

  • dims: names of the spatial axes (default (:x, :y, :z), or (:x1, :x2, ...) beyond 3D).
  • time_dim: name of the time axis (default :t).
  • xmins, xmaxs, tmin, tmax: override the bounding box (defaults: extent of the data). The integration measure (domain.spacing) is always derived from the axes themselves.

The parameters are copied, so later changes to params do not affect the dataset.

Examples

create_sim_data(x, u, t, params)                       # 1D + time, u[i, n]::SVector{M}
create_sim_data((x, y), u, t, params)                  # 2D + time, u[i, j, n]
create_sim_data((x, y, z), ρ, params; dims = (:r, :θ, :φ))   # static 3D scalar field
create_sim_data((x_grid, y_grid), u, t, params)        # ndgrid coordinate arrays
create_sim_data(x_traj, u_traj, t, params)             # particles over time

PDEStudioCore.register_stat! — Method

Registers a statistic evaluated through a calc_stat overload. kept_dims lists the dimensions that are retained; all others are integrated out. Valid values: :all, :space, :time, a single dimension name (e.g. :x) or a vector of dimension names (e.g. [:x, :t]; Symbol[] gives a scalar).

PDEStudioCore.rehash_sim_data — Method
rehash_sim_data(target_path; delete_old = true, filter_pairs = nothing, remove_keys = Symbol[], prompt_keys = Symbol[])

Re-normalises the parameters of a .jld2 file (or of every .jld2 file below a directory), recomputes the hash and stores the data under its new name. Use it after renaming or removing parameters, or after changes to the hashing.

Keywords

  • delete_old: remove the old file once the new one has been written.
  • filter_pairs: only process files whose parameters contain these exact pairs.
  • remove_keys: parameter keys to drop before rehashing.
  • prompt_keys: interactively ask (in the REPL) for new values of these keys for every file.

Returns a vector of old_path => new_path pairs.

PDEStudioCore.resample_eulerian — Method
resample_eulerian(data::ESimData, res::Tuple)

Resamples the solution and all statistics that keep spatial/temporal dimensions to the spacetime resolution res. Space is interpolated linearly, time with nearest-neighbour (constant) interpolation to avoid cross-fading between snapshots. Resampled axes are uniform and span the old axes' node range; axes whose resolution does not change are kept as they are. Returns data itself if it already has the requested resolution.

PDEStudioCore.run_all_simulations — Method
run_all_simulations(config::SimulationConfig; force_overwrite = false, calculate_stats = false,
                    force_stats = false, post_process = true, parallel = false)

Runs the complete pipeline for a SimulationConfig:

  1. includes config.sources into the target module,
  2. runs every task of generate_tasks whose data is not on disk yet (all of them with force_overwrite), in parallel over Julia threads with parallel = true,
  3. with calculate_stats = true, evaluates missing statistics using the reference factory config.reference (params -> (x -> u_exact)); statistics that were dropped earlier for lack of a reference are evaluated again once a reference is configured. force_stats = true recomputes every registered statistic without rerunning the simulations,
  4. with post_process = true, calls config.postprocess(data) for every dataset and saves the data when it returns true.

Failures of individual tasks are logged and do not abort the batch.
